# What is not in this kit

The kit comes from a personal setup. These parts were left out because they only make sense there.

| Left out | Why |
| --- | --- |
| Morning briefing and other scheduled jobs | Personal routines. |
| Circle sleep and weekend sleep | Tied to one person's hours and machines. |
| Health check and upstream recap jobs | Check one specific hub, Mac and set of circles. |
| Setup backup job | Copies one person's files to one private repo. |
| Brain notes, projects folder, `circles.tsv` | Personal notes and project lists. `CIRCLES_MAP` replaces the one file Invoke read from them. |
| Rule gates for Claude Code (`gates.py` and its tests) and the alert hooks that go with them | Enforce one person's working rules, repos and people. |
| Brain sync, sync lock | Syncs that person's notes folder between two machines. |
| Claude usage scraper | Reads status lines of that person's panes and accounts. Invoke keeps the usage strip but reads a plain JSON file (`USAGE_FILE`) that you can fill any way you like. |
| Telegram bridge | The older bridge for one person's bot and chat. Invoke replaced it. |
| Pane setup (builder helper pane, remote Claude pane launcher, standing leads and their watchers, Seance terminal config, hook JSON) | Layout for one hub and one Mac. Invoke only needs a Seance with leads; how they start is up to you. |
| Crew dance demo script | A demo helper wired to that person's circles. |
| One extra personal Claude theme | Named for one person. The twelve Seance themes are kept. |
| Project, circle, host, login and people names | Replaced by config values or generic words everywhere. |
